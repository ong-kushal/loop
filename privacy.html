This page explains the main privacy behaviors in the current Loop app. It is a product overview, not a substitute for a complete legal privacy policy.

Account and profile information

Loop uses Supabase Authentication for sign-in. Profile information can include a username, display name, profile picture and bio. Profiles are readable publicly in the current app.

Public posts and media

Posts, captions, comments and uploaded post media are publicly readable in the current app. Do not upload content you intend to keep private. You can delete your own posts from Loop.

Private messages

Direct messages are stored in Supabase and the app’s row-level security policies restrict message access to the sender and recipient. Do not treat messages as end-to-end encrypted.

Optional location

City and region are optional and are used to improve local recommendations. The app stores these labels in private location records. If you use browser-assisted location detection, the browser sends coordinates to the BigDataCloud reverse-geocoding service to obtain city and region. Loop does not persist the precise coordinates. The provider may process request metadata such as your IP address.

Service providers and early-stage limitations

Loop currently relies on Supabase for authentication, database, storage and realtime features, and on public content delivery for uploaded media. The project is an early-stage beta; storage, retention, security and legal documentation should be reviewed before a broad public launch.

Questions or privacy concerns

Loop does not yet publish a dedicated support contact in this starter project. Do not include sensitive personal information in public posts or profile fields.
